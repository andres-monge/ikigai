# Concepts

Shared domain vocabulary for this project — entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound and ce-compound-refresh process learnings; direct edits are fine. Glossary only, not a spec or catch-all.

## Revelio Method

### Your North Star
The explorer's confirmed direction for the contribution they want to make, used to judge whether proposed paths serve the same purpose. A new interest can prompt reflection on this direction without automatically changing it.

### Purpose Path
A distinct direction the explorer could try in service of Your North Star, framed around work they might engage with and what a small project could teach them. Interest in a path does not itself select it.

### Purpose Path set
The group of three equally weighted Purpose Paths offered together for comparison. Revising the group creates a new set while retaining the earlier set as history; the explorer sees the current offered group.
