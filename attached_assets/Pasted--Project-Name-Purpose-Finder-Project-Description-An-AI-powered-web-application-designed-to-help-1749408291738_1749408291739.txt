# Project Name
Purpose Finder

## Project Description
An AI-powered web application designed to help career-switchers and students find their *ikigai* (a reason for being) and navigate their career path. The application, guided by an AI persona named Nami, will go beyond simple skills-matching to incorporate a user's core values, personality, and life priorities. The MVP will focus on delivering three distinct and actionable ikigai-aligned career paths based on a comprehensive user assessment. The platform will be fully bilingual (English and Spanish) from launch.

## Target Audience
- Career-switchers and students, treated as a unified group for the MVP.

## Desired Features
### Stage 1: Purpose Discovery
- [ ] User completes a structured, multi-part questionnaire to identify their passions, skills, values, and economic needs.
- [ ] The AI (Nami) analyzes the user's input.
- [ ] The system generates and displays a summary of the user's core drivers (Energy, Edge, Impact, Economic Reality).
- [ ] The system presents three distinct "Purpose Paths" for the user to choose from.
    - [ ] Each path includes a title, a short description, and a breakdown of how it aligns with the four ikigai dimensions (Love, Good at, World Needs, Pay).
    - [ ] Each path includes a high-level action plan or strategy (e.g., "Bootstrapped MVP in 6 mo").
- [ ] The system provides a comparative table with estimated salary ranges for the suggested paths, generated using real-time web search to ensure data is current and localized.
    - [ ] The AI must cite the URLs of its sources for the salary data.
- [ ] User can initiate a chat-based conversation with Nami to refine or request changes to the generated suggestions.
- [ ] User can export their results page to a PDF document.

### Stage 2: Action Plan & Guidance (Post-MVP)
- [ ] Once a user selects a path, the AI generates a detailed, step-by-step action plan.
- [ ] The action plan includes key milestones (e.g., side project ideas, specific skills to learn, networking goals).
- [ ] The system recommends specific educational resources (YouTube courses).
- [ ] User can export their results page to a PDF document.

### AI & Core Technology
- [ ] AI persona "Nami" will have a personality inspired by Paul Graham's essays and stoic principles (encouraging, wise, action-oriented).
- [ ] The core AI will be powered by a Gemini model, specified via an environment variable for easy updates (initial model: `models/gemini-2.5-flash-preview-05-20`).
- [ ] The web application will be built and deployed using Replit.

### General
- [ ] No user accounts will be required for the MVP; user session data will be stored temporarily in the browser.
- [ ] Full bilingual support for English and Spanish across the entire user interface and AI interactions from day one.

## Design Requests
- [ ] Sleek and modern UI. Responsive and mobile-friendly.
- [ ] The output of the ikigai analysis should be clearly structured and presented in a format similar to the user's example.
    - [ ] A summary section ("What's popping out of your answers").
    - [ ] A clear, table-based comparison of the three ikigai options.
    - [ ] A secondary table providing salary benchmarks.
- [ ] A clean, intuitive chat interface for interacting with Nami for refinements.
