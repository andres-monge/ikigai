### Analysis of the Problem

The root cause of the `400 Bad Request` error is a subtle but critical mismatch between the Gemini model you are using (`gemini-2.5-flash`) and the specific tool name you are providing in your REST API call to enable search.

Here's the breakdown:

1.  **Correct Capability, Incorrect Implementation:** Your provided `flash_details` documentation is correct. The `gemini-2.5-flash` model *does* support "Search grounding". However, the *way* you ask the API to perform the search has changed between model families.

2.  **Two Different Search Tools:** The `grounding_docs` you provided reveal the core of the issue. There are two distinct tools mentioned:

      * **`googleSearchRetrieval`**: The documentation explicitly states, "**Note that Google Search retrieval is only compatible with the 1.5 models...**" Your code is currently using this tool name.
      * **`googleSearch`**: The documentation introduces this as the method for newer models, stating, "**Starting with Gemini 2.0, Google Search is available as a tool.**"

3.  **The Error:** You are using a Gemini 2.x model (`gemini-2.5-flash`) but sending the API payload for a 1.5 model (`{ googleSearchRetrieval: {} }`). The Gemini API sees this as an invalid argument for the specified model and correctly returns a 400 error.

The comment in your `server/grounding.ts` file even hints at this: `// Per the documentation, \`googleSearchRetrieval\` is the correct tool for 1.5 models.\` This is true, but your application is using a 2.5 model.

### The Fix

The solution is to update the `tools` object in your `server/grounding.ts` file to use the correct tool name for the `gemini-2.5-flash` model.

**File to Modify**: `server/grounding.ts`

**Function to Modify**: `generateWithRetry`

You need to change the `if (useSearch)` block to provide the correct tool definition.

```typescript
// server/grounding.ts

export async function generateWithRetry({
  prompt,
  isJsonMode = false,
  useSearch = false,
  maxRetries = 3,
  temperature = 0.7,
}: GeminiRequestOptions): Promise<GeminiCandidate> {
  if (!GEMINI_API_KEY) {
    throw new Error("Gemini API key is not configured in .env.local");
  }

  const url = `${BASE_URL}/${GEMINI_MODEL}:generateContent?key=${GEMINI_API_KEY}`;

  const generationConfig: Record<string, any> = {
    temperature,
  };
  if (isJsonMode) {
    generationConfig.response_mime_type = "application/json";
  }

  const body: Record<string, any> = {
    contents: [{ parts: [{ text: prompt }] }],
    generationConfig,
  };

  // =================================================================
  // START FIX: Modify the 'if (useSearch)' block
  // =================================================================
  if (useSearch) {
    // FIX: The `googleSearchRetrieval` tool is only for Gemini 1.5 models.
    // For the newer Gemini 2.x series (including 2.5-flash), the correct
    // tool must be specified as `googleSearch`. This was the cause of the
    // "Search Grounding is not supported" error.
    body.tools = [{ googleSearch: {} }];
  }
  // =================================================================
  // END FIX
  // =================================================================

  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      const response = await fetch(url, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(body),
      });

      if (!response.ok) {
        const errorBody = await response.text();
        throw new Error(
          `Gemini API error: ${response.status} ${
            response.statusText
          } | Body: ${errorBody}`
        );
      }

      const data = await response.json();
      const candidate = data.candidates?.[0];

      if (!candidate) {
        throw new Error("No candidate received from Gemini API");
      }
      return candidate as GeminiCandidate;
    } catch (error) {
      console.error(`Gemini API attempt ${attempt} failed:`, error);
      if (attempt === maxRetries) {
        throw error;
      }
      await sleep(1000 * Math.pow(2, attempt - 1));
    }
  }
  throw new Error("Gemini API request failed after all retries.");
}
```

By making this change, you are now sending the correct payload to the Gemini API for your `gemini-2.5-flash` model.
